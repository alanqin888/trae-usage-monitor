# Privacy Policy for Trae Token Sync

Last updated: May 19, 2026

Trae Token Sync ("the Extension") is a companion tool designed to synchronize your Trae AI login authentication token with the local VS Code extension environment.

## 1. Data Collection and Usage
The Extension only accesses the `trae.ai` domain to intercept and capture the authentication token necessary for the Trae Usage Monitor VS Code extension to function. 
- **Authentication Information:** The Extension captures your Trae session token strictly for the purpose of local synchronization.
- **No Personal Information:** We do not collect names, email addresses, or any other personally identifiable information.
- **No Browsing History:** We do not track your browsing history or monitor activity on other websites.

## 2. Data Storage
The captured token is temporarily stored securely in the browser's local storage and is exclusively accessible by the Extension and the connected local VS Code environment.

## 3. Data Sharing
We do not sell, trade, or otherwise transfer your data to any outside parties. The token never leaves your local machine and is not sent to any remote servers (other than the official Trae AI API as intended by the user).

## 4. Contact
If you have any questions regarding this privacy policy, please open an issue on our GitHub repository.
